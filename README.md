# mutong-smart-livestock
牧瞳·面向中小型猪场的多模态智慧决策中间件——开源数据中间件原型与传感器仿真

## 传感器数据采集链路验证

本项目传感器数据采集链路已通过Wokwi在线仿真环境验证。

- 仿真平台：ESP32-S3 + DHT22温湿度传感器
- 通信协议：单总线 → UART串口 → JSON格式化输出
- 波特率：115200

👉 [在线查看仿真项目](https://wokwi.com/projects/462918624503874561)

## 模拟数据生成器

基于《农业工程学报》猪舍环境参数日变化规律研究成果，生成7天×24小时分钟级猪场多模态传感器数据。

- 数据维度：温度、湿度、氨气、CO₂、群体活动量、耳标体温、采食量
- 预设异常场景：低温应激、氨气蓄积、疫病前兆
- 总数据量：10,080条

运行方式：
​```
python generate_data.py
​```
